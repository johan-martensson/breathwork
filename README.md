# Breathwork

A guided breathing app that runs in the browser and can be added to an iPhone home screen.

Each round: deep breaths with an animated guide → breath hold after exhaling (timed) → a recovery breath held for a set time. Session history is stored only on the device.

**Install on iPhone:** open the site in Safari → Share → Add to Home Screen.

> Practice sitting or lying down. Never do breathing exercises in or near water, while driving, or anywhere fainting could be dangerous.

When changing files, bump `APP_VERSION` in `app.js` and `CACHE` in `sw.js` together. The version is shown at the bottom of the home screen.
